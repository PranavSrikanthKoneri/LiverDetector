# CHAOS-derived numerical texture QC reference

`chaos_texture_qc_v1.json` contains derived numerical measurements from the 20
training MRI patients in CHAOS v1.03, not medical images or segmentation arrays.
Changes: in-plane resampling, liver-mask erosion, GLCM extraction and numerical
perturbation measurements, as described in `docs/texture_quality.md`.

Source: Ali Emre Kavur, M. Alper Selver, Oguz Dicle, Mustafa Baris, N. Sinem Gezer
(2019), CHAOS – Combined (CT-MR) Healthy Abdominal Organ Segmentation Challenge
Data, v1.03. https://zenodo.org/records/3431873
